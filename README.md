# FCTUC-TCD

Project made for 2024/2025 edition of Data Science Topics course

## Summary

**Theme**: Voice-Controlled Wheelchair

**Objective**: This project targets speech recognition using a subset of the [Speech Commands Dataset](https://www.emergentmind.com/topics/speech-commands-dataset) and is separated into two modules: A and B. Module A covers various approaches to data analysis, preparation, and cleaning, as well as a descriptive analysis of feature engineering procedures. Module B tackles the machine learning pipeline, ranging from applied feature extraction to a comparative study of hyperparameter-tuned ML algorithms, namely k-NN and MLP.

## Repository Structure
